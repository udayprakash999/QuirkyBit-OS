# QuirkyBit OS
it is a mini smartphone like operating system UI built using html css and js 

## 🌐 Live Demo

[View QuirkyBit OS](https://udayprakash999.github.io/QuirkyBit-OS/)

# Features

- smartphone style user interface
- live digital clock 
- photo app to upload
- notes app
- calculator app
- quick doc app to write and save text
- interactive popup to open and close apps
- animated video wallppr

# Tech Stack

- HTML5
- CSS3
- JavaScript
- FONTAWESOME
- FILE READER
- BATTERY STATUS
